Allgemeine Hinweise

Der Schutz Ihrer persönlichen Daten ist uns ein wichtiges Anliegen. Die Werkzeuge dieses Portals arbeiten grundsätzlich lokal im Browser (client-seitig). Eingaben, Unterschriften und Fotos werden nicht an Dritte übertragen. Eine Übertragung an einen Server findet nur statt, wenn Sie dies ausdrücklich auslösen (siehe „Speicherung auf dem eigenen Server“).

  • Keine Übertragung von Eingaben an Dritte
  • Speicherung grundsätzlich nur auf dem eigenen Gerät
  • Keine Cookies, keine Analyse- oder Tracking-Werkzeuge

Diese Website informiert über das Thema Arbeitssicherheit und bietet Werkzeuge zur Eigenkontrolle. Sie ist ein rein privates, nicht-kommerzielles Projekt.

Erhebung und Speicherung personenbezogener Daten

Eingegebene Informationen (z. B. Marktnummer, Namen, Antworten der Checklisten, Bemerkungen und Unterschriften) werden im lokalen Speicher des Browsers (localStorage) auf dem verwendeten Gerät zwischengespeichert, damit sie bei einem versehentlich geschlossenen Fenster nicht verloren gehen. Diese Daten verlassen das Gerät nicht und können jederzeit über „Zurücksetzen“ oder das Löschen der Websitedaten im Browser entfernt werden. Fotos werden nur im Arbeitsspeicher verarbeitet.

Speicherung auf dem eigenen Server

Im Arbeitssicherheits-Audit (audit.html) kann eine Begehung über „Direkt auf NAS speichern“ an einen vom Betreiber selbst betriebenen Server (Synology NAS) gesendet werden. Das geschieht ausschließlich auf ausdrücklichen Knopfdruck; dabei werden die Begehungsdaten einschließlich der eingegebenen Namen und Unterschriften übertragen. Ein externer Dienstleister ist daran nicht beteiligt. Für die eigenständigen Anwendungen im Portal (z. B. ASiC Handel) gelten deren eigene Datenschutzhinweise.

Cookies

Diese Website verwendet keine Cookies oder Tracking-Technologien. Die oben beschriebene lokale Speicherung im Browser dient ausschließlich der Funktion der Werkzeuge.

Eingebettete Inhalte und externe Dienste

Alle Bibliotheken (Symbole, PDF-Erzeugung) sind lokal in die Anwendung eingebunden; es werden keine externen Dienste zur Laufzeit nachgeladen (kein Google Fonts, kein CDN, kein Analytics o. Ä.). Links zu externen Seiten (z. B. Gesetzestexte, DGUV, BGHW) werden erst beim Anklicken aufgerufen.
