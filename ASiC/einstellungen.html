Server-Verbindung

Im Regelbetrieb liegen App und Server-Skripte auf demselben Server – dann bleibt die Server-Adresse leer und nur der Zugriffsschlüssel wird eingetragen, falls die EDV einen vergeben hat.

Nur nötig, wenn die App über eine andere Adresse geöffnet wird als der Server. Ohne abschließenden Schrägstrich, z. B. https://server.firma.de/asic.

Den Wert erhalten Sie von der EDV. Er wird bei jeder Server-Anfrage mitgeschickt.

Öffnen Sie eine Begehung aus dem Team-Archiv, sehen die anderen dort „geöffnet auf …“ mit diesem Namen. Ohne Namen steht dort „einem anderen Gerät“.

Über diese App & Diagnose

Funktioniert etwas nicht? „Diagnose erstellen“ prüft die Verbindung und stellt den technischen Zustand dieses Geräts zusammen. Den Text an die EDV schicken – er enthält keine Begehungsinhalte, keine Namen und nie den Zugriffsschlüssel.


        

    




    
    
    

    

        
Fragen & Antworten

        
Häufige Fragen zu den Einstellungen


        

            Wann muss ich eine Server-Adresse eintragen?
            

                
Fast nie. Standardmäßig sucht die App save.php, list.php und load.php im selben Verzeichnis wie diese Seite. Das passt, wenn App und Server-Skripte auf demselben Server liegen (Regelbetrieb).

                

                    Mehr Details
                    

                        
Eine Adresse ist nur nötig, wenn die App über eine andere Adresse aufgerufen wird (z. B. eine Test-Installation) und trotzdem auf den Firmenserver zugreifen soll. Ein abweichender Port wird direkt in der Adresse angegeben, z. B. https://server.firma.de:8443/asic.

                    

                

            

        


        

            Was ist der Zugriffsschlüssel?
            

                
Ein langes Kennwort, das die EDV auf dem Server festlegt. Ist dort ein Schlüssel eingerichtet, nimmt der Server Speicher- und Ladeanfragen nur mit diesem Schlüssel an.

                

                    Mehr Details
                    

                        
Der Schlüssel muss exakt übereinstimmen – auch Groß-/Kleinschreibung und Leerzeichen zählen. Mit dem Auge-Symbol lässt er sich zur Kontrolle anzeigen. Ist auf dem Server kein Schlüssel eingerichtet, hat dieses Feld keine Wirkung.

                    

                

            

        


        

            Was prüft „Verbindung testen“?
            

                
Die App fragt beim Server die Liste der gespeicherten Begehungen ab – mit der eingetragenen Adresse und dem Schlüssel. Es wird nichts gespeichert oder verändert.

                

                    Mehr Details
                    

                        
    
                            
  • Verbindung in Ordnung – Server erreichbar, Schlüssel passt; die Anzahl der Begehungen im Team-Archiv wird angezeigt.
    • 
                            
  • Ungültiger oder fehlender Zugriffsschlüssel – Schlüssel fehlt oder weicht ab.
    • 
                            
  • Datenordner nicht gefunden – auf dem Server stimmt der Pfad in config.php nicht; bitte die EDV informieren.
    • 
                            
  • Server nicht erreichbar – keine Netzverbindung, VPN aus oder falsche Adresse.
    • 
                        

                        
Der Test verwendet die gerade eingetragenen Werte, auch wenn sie noch nicht gespeichert sind. Dauerhaft übernommen werden sie erst mit „Speichern“.

                    

                

            

        


        

            Server-Adresse und App liegen auf verschiedenen Servern – was ist zu beachten?
            

                
Dann muss der Server-Betreiber CORS-Zugriff für die Adresse der App erlauben, sonst blockiert der Browser die Anfrage aus Sicherheitsgründen.

                
Sobald der Server nicht mehr nur über ein geschütztes Netz (Firmennetz oder VPN) erreichbar ist, ist ein Zugriffsschlüssel dringend zu empfehlen.

            

        


        

            Wo werden diese Einstellungen gespeichert?
            

                
Nur im Browser-Speicher dieses Geräts. Auf einem anderen iPad oder in einem anderen Browser müssen sie neu eingetragen werden.

                

                    Mehr Details
                    

                        
„Zurücksetzen“ löscht Server-Adresse und Zugriffsschlüssel auf diesem Gerät. Begehungen, Fotos und das Archiv bleiben davon unberührt.

                    

                

            

        


        

            Wo stelle ich den Zugangscode ein?
            

                
Nicht hier – den Zugangscode legt der Betreiber auf dem Server in der Datei zugang-config.js fest. Er wird nur in der installierten App-Ansicht und nur einmal je Gerät abgefragt.
