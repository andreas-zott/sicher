NAS-Server-Adresse

Standardmäßig erwartet die App save.php, list.php und load.php im selben Verzeichnis wie diese Seite selbst — das funktioniert, wenn die App direkt über die Synology (bzw. deren Tailscale-Adresse) aufgerufen wird.

Wird die App stattdessen über eine andere Adresse aufgerufen (z. B. GitHub Pages) und soll trotzdem auf einen Server zugreifen, kann hier dessen Adresse hinterlegt werden.

Ohne abschließenden Schrägstrich eingeben. Ein abweichender Port lässt sich direkt in der Adresse angeben (wie im Beispiel oben) — dafür ist kein eigenes Feld nötig. Leer lassen, um beim bisherigen Verhalten (gleiche Adresse wie die App selbst) zu bleiben.

Wird bei jeder Anfrage als Kopfzeile mitgeschickt und vom Server geprüft (sofern dort ein Schlüssel eingerichtet ist — siehe Technische Dokumentation). Ohne konfigurierten Schlüssel auf dem Server hat dieses Feld keine Wirkung.

Wichtig: Liegt der Server auf einer anderen Adresse als die App selbst, muss der Server-Betreiber dort zusätzlich CORS-Zugriff für die Adresse dieser App erlauben — sonst blockiert der Browser die Anfrage aus Sicherheitsgründen. Bei gleicher Adresse (wie im Regelbetrieb über die Synology) ist das nicht nötig. Ein Zugriffsschlüssel wird dringend empfohlen, sobald der Server nicht mehr nur über ein geschütztes Netz (z. B. Tailscale) erreichbar ist.
