Datenschutzerklärung

1. Verantwortlicher

Andreas Zott — Kontaktdaten siehe Impressum.

2. Kurz gefasst

Diese Anwendung läuft vollständig im Browser des jeweiligen Geräts. Es findet keine automatische Übertragung eingegebener Daten an einen Server statt.

3. Welche Daten verarbeitet werden

Beim Ausfüllen einer Gefährdungsbeurteilung werden folgende Daten eingegeben und ausschließlich lokal im Browser gespeichert (localStorage):

  • Betriebsdaten (Unternehmen, Standort, Name der beurteilenden Person, Datum)
  • Angaben zur Maschine bzw. Tätigkeit
  • Risikobewertungen und Freitextangaben
  • Handschriftliche Unterschriften (als Bilddaten im Browser)

Diese Zwischenspeicherung dient ausschließlich als Schutz vor Datenverlust bei versehentlichem Neuladen der Seite. Es wird keine Historie oder Archiv geführt — beim erneuten Aufrufen derselben Gefährdungsbeurteilung wird der vorherige Zwischenstand überschrieben.

4. Export als PDF

Über die Funktionen „PDF speichern" bzw. „Teilen" wird aus den eingegebenen Daten eine PDF-Datei lokal im Browser erzeugt. Diese Datei verlässt das Gerät ausschließlich durch aktives Handeln der nutzenden Person (Speichern, Teilen per E-Mail oder über eine andere App). Eine automatische Übertragung findet nicht statt.

5. Keine Analyse- oder Trackingdienste

Diese Anwendung verwendet keine Cookies zu Analysezwecken, keine Werbe- oder Trackingdienste Dritter und überträgt keine Daten an externe Server.

6. Lokale Bibliotheken

Zur PDF-Erzeugung wird die quelloffene Bibliothek jsPDF verwendet, die lokal in die Anwendung eingebunden ist — es erfolgt keine Anfrage an einen externen Server hierfür.

7. Löschung

Die lokal gespeicherten Zwischenstände können jederzeit über „Zurücksetzen" im jeweiligen Formular oder durch Löschen der Website-Daten im Browser entfernt werden.
